# Security Policy

## Status

SignalTrace is research tooling that runs locally. It is not a hosted service,
and its results are not a forensic or legal determination. Only the latest
commit on `main` is maintained.

## Reporting a Vulnerability

Please report security issues privately through GitHub's
**Security → Report a vulnerability** form on this repository. Do not open a
public issue or pull request that contains exploit details, credentials, or
recordings of real people.

When reporting, please include:

- The affected component or file path
- A minimal description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation, if known

Reports are handled on a best-effort basis; there is no service-level
guarantee or formal vulnerability-response program.

## Scope

This policy covers the source code in this repository. It does not cover
third-party models, datasets, or dependencies; please report issues in those
to their maintainers.
